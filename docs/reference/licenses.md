# 出典とライセンス

このデータセット全体に単一のライセンスは適用しません。リポジトリ固有アセットと外部データは、別の条件に従います。

リポジトリ固有アセットは CC0 1.0 Universal で提供します。

- <https://creativecommons.org/publicdomain/zero/1.0/>
- <https://creativecommons.org/publicdomain/zero/1.0/legalcode>

作業者は、出典別のライセンス、根拠 URL、帰属文言、利用条件、加工内容を[出典とライセンスの台帳](sources-and-licenses.md)で確認します。

現在の更新元は`config/sources.json`、残存情報を含む出典は台帳で管理します。出典表示と加工内容を維持してください。
