# 文書の執筆規範

このrepositoryの文書はDiátaxisを使います。
Diátaxisは、tutorial、how-to guide、reference、explanationを分けます。

- `docs/tutorials/`: 初学者が学習のために完了する手順
- `docs/how-to/`: 特定の目的を達成する手順
- `docs/reference/`: 実装と契約を網羅する事実
- `docs/explanation/`: 背景、判断、設計意図

## 表記

1. 日本語を使用してください。
2. 指示は明確かつ具体的に記述してください。
3. 3語を超える単語で構成される名詞は書かないでください。
4. 一般的に理解できない略語には、本文内で正式名称をカッコ（ ）に記載してください。
5. 一般的に理解できる略語には、冗長な正式名称を書かないでください。
6. 動詞の承認された形式だけを使用してください。
7. 不定詞形、命令形、単純現在形、単純過去形、単純未来形、形容詞としての過去分詞を使用してください。
8. 複雑な動詞構文で助動詞を使用しないでください。
9. 現在形の動詞は、技術名詞または技術名詞を修飾する語として使用してください。
10. 能動態を使用してください。行為者が不明な描写だけで受動態を使用してください。
11. 手順書は20語以内、説明文は25語以内で記述してください。
12. 文を短くするために、主語や動詞を省略しないでください。
13. 複雑な内容には縦書きリストを使用してください。
14. 1文につき1つの指示を記述してください。
15. 段落ごとに1つのトピックだけを記述してください。
16. 各段落は6文以内にしてください。
17. 安全に関する指示は、明確な命令または条件から始めてください。
18. CJK文字とLatin文字の間に半角スペースを入れないでください。

## 作成とレビュー

READMEには、目的、最初の検証、各文書への入口だけを置いてください。
実装、workflow、生成物、testsと照合してから文書を変更してください。
実装にない機能を現行機能として書かないでください。

文書変更後、文書構成テスト、全tests、`validate`、`git diff --check`を実行してください。

AIエージェントもこの規範を守ります。
rootの`AGENTS.md`はこの文書を参照します。
