# WAM NET参考資料

WAM NETの障害福祉サービス等情報検索オープンデータは、施設の検索対象と座標を整備する際の参考資料です。このリポジトリで残るWAM由来の施設情報には、配布ページの利用条件が適用されます。

| 項目 | 内容 |
| --- | --- |
| 配布元・利用条件 | <https://www.wam.go.jp/content/wamnet/pcpub/top/sfkopendata/> |
| 帰属 | WAM NET |
| 対象 | 相談支援4サービスの東京都千代田区の施設 |
| 加工 | 対象地域の抽出、同一施設の集約、施設識別子と検索情報の整理 |

WAMの定期取得や更新処理は設けません。現在の検索対象は`inputs/facilities.json`、関連付けの更新元はOpenStreetMapです。施設UUIDと有効な座標を維持し、残る情報の帰属を[出典とライセンスの台帳](sources-and-licenses.md)と公開ページへ記載します。
