# Design

## Context

現在のrecordは1検索入力・1 OSM要素・1 Placeの対応で、建物名のrecordが中の施設に紐づく例がありました。昌平童夢館は神田児童館（node/2263796343、5階）、いきいきプラザ一番町は一番町高齢者在宅介護支援センター（node/1655905663）、岩本町ほほえみプラザは社会福祉施設（node/14337499601）、西神田コスモス館はKSJ2由来の支援センターノードに紐づいていました。カテゴリもこの施設のタグから決まっていました。

## Goals / Non-Goals

**Goals:**

- 建物と施設を別UUIDのPlaceとして並列に登録する
- 建物POIは建物の種類（コミュニティセンター1307、福祉施設1499）、施設POIは施設のコードで公開する
- 西神田コスモス館の保留を建物要素の確定で解除する

**Non-Goals:**

- 幼稚園・保育園の施設POI（別change）
- 高齢者施設の施設POI（別change）
- 富士見わんぱくひろば・西神田児童センターの施設POI（OSM要素待ち）
- `schema:containedInPlace`などの包含関係の導入
- 分類パイプラインや確認Issueの変更

## Decisions

### 建物と施設は別のPlaceとし、包含関係を持たない

1 record = 1 OSM要素という既存モデルで足ります。区の施設案内も複合施設と入居施設を別項目で並べており、地図・ナビでの施設探索では並列のPOIとして扱うのが自然です。要は「昌平童夢館」と「神田児童館」が別のIDを持ち、それぞれのカテゴリで公開されることです。包含関係を足す案は、公開スキーマ・検証・消費者側の変更を伴う割に、この用途では利点がありません。

### 建物POIのカテゴリは建物の種類に従う

建物は種類に応じて分類します。区民利用の複合施設（昌平童夢館、神田さくら館、富士見みらい館、ちよだパークサイドプラザ、西神田コスモス館）はコミュニティセンター（1307）、福祉施設の複合施設（いきいきプラザ一番町、岩本町ほほえみプラザ）は福祉施設（1499）です。カテゴリ判断の対象外にする特別な仕組みは作りません。規則（`amenity=community_centre`→1307、`amenity=social_facility`→1499）で決まる建物はそのまま、決まらない建物（昌平童夢館は`building=school`、西神田コスモス館は`building=yes`のみ）は人判断で確定します。いきいきプラザ一番町は付け替え後の再評価で1499、岩本町ほほえみプラザは現行の1499を維持します。

### 施設POIは施設のコードで分類し、建物とは別のUUIDを持つ

神田児童館といずみこどもプラザは児童館（1403）です。富士見小学校は小学校（1503）で、参照を施設ノードから建物way/460729041へ変えます。神田児童館の入力は「児童館」と`community_centre`の両方に当たるため規則は決めず、人判断で1403にします。いずみこどもプラザは`kindergarten`タグで規則が決まらないため、人判断で1403にします。

### 付け替え後のカテゴリは人判断で確定する

`assoc --osm-id`で参照を変えると保存済みカテゴリの`osmId`が変わりstaleになります。OSMミラー`site/mirrors/osm.json`は月次更新で作られるため、新しく追加・変更された建物要素はまだ含まれず、`./fac category refresh`は新しい要素のタグを読めません。したがって、付け替えた建物・施設のカテゴリは`./fac category assign`で人判断として確定します。次の月次更新の後も保存済み判断は維持されます。

### 西神田コスモス館の保留は解除する

建物relation/9323146が確定したので、`./fac assoc --osm-id relation/9323146`で人判断として記録し、保留を解除します。カテゴリはコミュニティセンター（1307）を人判断で確定します。西神田児童センターはOSM要素がないため、このchangeでは追加せず、OSM収録後の別changeに回します。

## Risks / Trade-offs

- [同じ住所に建物と施設のPOIが並ぶ] → 意図した状態。建物はコミュニティセンター、施設は児童館・小学校として別々に公開される
- [建物の1307（公民館）が実態と合わない建物がある] → 区民利用の複合施設としての分類。個別に合わなければ`category assign`で変えられる
- [高齢者施設の個別POIはまだない] → 建物を福祉施設（1499）として公開し、特別養護老人ホームや在宅サービスセンターの個別POIは別changeで追加する
- [富士見わんぱくひろば・西神田児童センターが未登録のまま] → OSM要素の収録後に別changeで追加する

## Migration Plan

1. 建物POIの付け替えとカテゴリ確定
2. 施設POIの追加とカテゴリ確定
3. 富士見小学校の付け替え
4. 文書更新と検証
5. ロールバックはデータコミットを戻す
